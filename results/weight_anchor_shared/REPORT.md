## Runtime (not measured)
- No simulated timings were recorded (all models are fp32-dequantized, so simulation time says nothing about packed cost).
- K = 4 cost condition: 50·C_Q4 + 13·C_high + overhead < 50·C_high. For A the high layer is Q4 + D̂ (two 4-bit products or reconstruction), so C_high ≥ C_Q4-class work twice;
  shared storage does not relax this condition. Any future speed claim must also beat H_shared-50 and H8-50 at matched latency (both are in the tables above).

## Reading (kept narrow)
- **H1 (useful anchor): partially.** The selected shared anchor H_shared (A-GPTQ) reduces Q4's endpoint latent MSE by 69% (ratio 0.308 [0.178, 0.522]),
  but it is ~10× worse than the independent H8 (ratio 10.5 [5.4, 21.2]). Four refinement bits on a frozen heig-8 base, built with the fixed projected
  metric, give a far weaker anchor than an independently built W8. B (fixed prefix) is weaker still (dev H_B/Q4 0.77): the frozen W4 cells cannot
  express most of the needed correction (17% of elements clipped, 99% of B's error energy).
- **H2 (preserve the independent hybrid's benefit): not supported under the frozen margins.** R_shared is 1.95× R8's mean latent MSE
  [1.16, 3.53] with ΔLPIPS +0.034 [+0.019, +0.053]: degradation beyond the 1.10 / 0.01 margins is established. Retained gain B = 0.78 [0.55, 0.95].
  Reuse itself works with the shared anchor (R_shared vs A_shared −54%), but R_shared is also worse than plain H_shared (1.18× [1.00, 1.50]),
  so in this configuration the hybrid does not beat its own anchor model at 50 steps.
- **H3 (storage): supported.** The packed shared artifact is 223.0 MB (23.9%) smaller than the equally packed independent pair, i.e. the ideal
  4-bit/weight payload saving; whole-model saving is ~24% of the pair, not 33%, because adaLN, fp32 other tensors, scales and carries remain.
- **What this does not show:** any speed or device-RAM benefit (none measured; simulation holds fp32-dequantized models), anything about jointly
  optimized nested quantizers (MatGPTQ-style), other refinement calibrations, or generation quality.
- **Next decision (not launched):** a joint construction that trades low-model accuracy against anchor accuracy would need its own low-model
  baseline and paired hybrid controls; it is a separate, separately budgeted follow-up.
