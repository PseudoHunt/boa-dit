## 2–3. Fraction removed at a shared step, and end to end

Removed at a shared step: Q and K projections, QKᵀ, softmax. V1/V2 keep a dense AV; V4 does AV over 32 entries per row; V3 replaces AV with a direct 31×31 depthwise convolution (2 · 961 · N · C FLOPs). At N = 256 that convolution costs more than dense AV (961 > 256 taps), so V3 removes less than V1. End to end = (k / 50) × 28 × removed / model total; both CFG branches share equally, so the fraction is the same with or without CFG.

| variant | N | block FLOPs removed | end to end, k = 10 | end to end, k = 15 |
| --- | ---: | ---: | ---: | ---: |
| V1/V2 dense stored map | 256 | 17.9% | 3.6% | 5.4% |
| V1/V2 dense stored map | 1024 | 21.1% | 4.2% | 6.3% |
| V1/V2 dense stored map | 4096 | 29.5% | 5.9% | 8.9% |
| V4 sparse top-32 | 256 | 19.4% | 3.9% | 5.8% |
| V4 sparse top-32 | 1024 | 27.4% | 5.5% | 8.2% |
| V4 sparse top-32 | 4096 | 47.9% | 9.6% | 14.4% |
| V3 offset kernel (direct 31x31 conv) | 256 | 13.0% | 2.6% | 3.9% |
| V3 offset kernel (direct 31x31 conv) | 1024 | 21.5% | 4.3% | 6.5% |
| V3 offset kernel (direct 31x31 conv) | 4096 | 43.7% | 8.7% | 13.1% |

Plainly: at N = 256 the saving is small (a few percent end to end even at k = 20), because the MLP and projections dominate a block. It grows with N because QKᵀ and softmax grow as N². Dense stored maps grow as N² too (V1 at N = 4096 is 16 · 4096² · 2 B = 537 MB per block, branch and step), so at high N only a compact form such as V3 is usable. Caveat on the V3 rows at N = 1024 / 4096: they assume a 31×31 kernel still suffices on a 32×32 / 64×64 grid. Section 6 finds the kernel uses its full support at 16×16; if that scales with the grid, a 64×64 grid needs up to 127×127 taps (2 · 16129 · N · C FLOPs), which is more than dense AV at N = 4096 (2 · N² · C, i.e. 4096 taps). The V3 compute saving at high N therefore depends on an untested property: a bounded kernel support.

Reading: the kernel is not compact. Early attention is a broad, near-uniform floor plus a weak local peak, and both spread over the whole 16×16 grid, so a 31×31 convolution needs its full support. The convolution path is therefore not cheap at this resolution. Whether the support stays bounded at larger grids (which would make it cheap relative to N²) is untested.
